# 简单小一点 SIMPLE SMALLER

macOS / Windows 上的图片、视频、PDF 压缩与裁切工具。全部在本机处理，不上传，不需要另装组件。

## 能做什么

- **图片**
  - 压缩：WebP / AVIF / JPG / PNG，可按宽、高或长边缩放，同一张图可出多档尺寸（网站 srcset）。
  - 截图类图片走无损 WebP，文字边缘不糊。
  - 可限体积，比如不超过 500 KB。
  - 裁切：按平台比例裁（小红书 3:4、公众号 2.35:1 等），默认居中取最大，每张可手调。
- **视频**
  - 压缩：H.264 / HEVC / GIF，可限体积（发群 25 MB）。
  - 剪辑：截取一段、按比例取景，同时导出封面。
  - 序列帧：抽成一张张图片，可打包 zip、另存拼图总览。
  - 只去声音：画面不重新编码。
- **PDF**
  - 压缩，文字保持矢量。
  - 合并（排序、删页）、拆分、转图片或长图、图片转 PDF。
  - 带密码的文件输入密码后照样处理；输出可以加打开密码。
- **配方**：格式、尺寸、裁切、命名、存放位置存成一个配方，批量文件统一使用；可以导出 `.smaller` 发给同事。

## 用起来

- **入口**：主窗口拖放、菜单栏小窗、访达里按住 ⌥ 点文件弹出圆环、右键「服务 → 用简单小一点处理」。
- **自动处理**：复制的截图自动换成压缩版（默认关）；监视截图、下载这类文件夹，新文件按配方自动处理。
- **原文件不动**：输出写在旁边。拖入文件夹时，按原来的目录结构写进「文件夹名-small」，再次拖入会跳过上次的输出。
- **撤销**：一键把这一批新文件移到废纸篓；失败的文件可以一键重试。
- **压完怎么用**：处理完的行可以直接拖进微信、浏览器；按空格快速查看；选中一行可以前后对比。
