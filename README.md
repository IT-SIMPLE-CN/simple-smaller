# 简单小一点 SIMPLE SMALLER

macOS / Windows 上的图片、视频、PDF 压缩与裁切工具。全部在本机处理，不上传，不需要另装组件。

- **图片**：压缩（WebP / AVIF / JPG / PNG，按宽出多档）· 裁切（按平台比例，批量逐张确认）
- **视频**：压缩（H.264 / HEVC / GIF，可限体积）· 剪辑（截取与比例裁切）· 序列帧
- **PDF**：压缩 · 合并 · 拆分 · 转图片 · 图片转 PDF
- **入口**：主窗口拖放、访达 ⌥ 点击 / 资源管理器 Alt 点击圆环、右键菜单、菜单栏、剪贴板

开发中，先做 macOS 版（macOS 14 起）。
