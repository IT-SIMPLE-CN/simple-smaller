# 规划（mac 版）

按使用场景排：先保证「拖进去、点开始、拿到结果」这条路在各种情况下都可靠，再补让日常更顺手的，最后是新能力。做完的打勾。

## 一、可靠性：任何情况下都不出错、不丢结果

- [x] 截断、损坏的图片报「文件不完整 / 文件损坏」，不再输出一张黑图
- [x] 完成统计把失败分开：「1 个完成 · 2 个失败」，体积只算处理成功的
- [x] 失败的可以一键重试（改了配方后重试同一批失败项），结果落回原本的输出位置
- [x] 加密 PDF：输入密码后处理，密码只在本次使用，不保存
- [x] 处理中阻止系统睡眠；处理中退出要确认
- [x] Dock 图标显示进度，完成后显示角标
- [x] 拖入的文件夹里有之前的输出（`-small` 文件夹、`-small` 文件）时跳过，不重复压缩
- [x] 视频拖入文件夹时输出进「文件夹-small」（原来逐段跑时落在原文件旁边）
- [x] 大批量：300 张 768 宽的图 8 秒处理完，峰值 253 MB；30 张 6016×6016 HEIC 峰值从 6.1 GB 降到 1.6 GB（读信息只读文件头、大图按内存限流、解码少一次整图拷贝）

## 二、顺手：省掉多余的步骤

- [x] 列表行直接拖出：把压好的文件拖进微信、浏览器、邮件
- [x] 空格键快速查看选中行的输出（系统 Quick Look）
- [x] ⌘1 / ⌘2 / ⌘3 切换图片、视频、PDF
- [ ] 菜单栏小窗的最近记录带缩略图
- [ ] 剪贴板图片处理完，结果卡「拷贝」后可以直接粘贴发出（已有，补验证）

## 三、新能力

参考同类工具（Clop、ImageOptim、Caesium、PDF Squeezer 等）的用户高频需求，只取和「本机、配方、一次输出」吻合的。

- [x] 剪贴板自动压缩（默认关）：复制的截图自动换成压缩版，粘贴到公众号、飞书就是小图
- [x] 监视文件夹：放进指定文件夹（如截图、下载）的新文件自动按配方处理
- [x] PDF：输出时加打开密码

暂不做：统一音量、水印、滤镜调色、云端处理、JPEG XL（偏离定位或平台支持差）。

以上界面已逐项实测（密码弹窗、拖出、快速查看、设置「自动」页、拖到配方、动图剪辑预览），剪贴板与监视文件夹在锁屏下实测。
